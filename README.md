# 🏠 StayFinder - Apartment Booking App

A modern and user-friendly mobile application built with Flutter that allows users to discover, filter, and book residential apartments easily.

The application provides a smooth booking experience with advanced search capabilities, apartment details, favorites management, and a responsive mobile interface.

# 🚀 Overview

StayFinder is a Flutter-based apartment booking application designed to simplify the process of finding suitable apartments.

Users can explore available properties, apply advanced filters, view detailed information, and manage their favorite apartments.

The project focuses on:

- Modern mobile UI/UX.
- Clean and maintainable Flutter architecture.
- Efficient state management.
- API integration.
- Smooth user experience.

---

# ✨ Features

## 🔐 Authentication

- User registration and login.
- Secure authentication flow.
- User session management.

---

## 🏠 Apartment Discovery

- Browse available apartments.
- View apartment cards with essential information.
- Display apartment images.
- View pricing and location details.
- Explore apartment descriptions.

---

## 🔎 Advanced Filtering System

Users can find apartments based on:

- 📍 Location.
- 💰 Price range.
- 🛏 Number of bedrooms.
- 🚿 Number of bathrooms.
- 🏠 Apartment type.
- ⭐ Rating.
- Available facilities.

The filtering system helps users quickly find apartments matching their requirements.

---

## ❤️ Favorites

- Add apartments to favorites.
- Remove apartments from favorites.
- Manage saved apartments.

---

## 📄 Apartment Details

Each apartment contains:

- Image gallery.
- Description.
- Price information.
- Location.
- Facilities.
- Owner information.
- Booking options.

---

## 📅 Booking System

- Select booking dates.
- Submit booking requests.
- Manage reservations.

---

## 🎨 User Interface

- Smooth navigation.

# ⚙️ Installation

Clone the repository: git clone 


Navigate to project folder: cd apartment-booking-app

Install dependencies: flutter pub get 

Run the application:
copy and paste this command in the terminal: flutter run
